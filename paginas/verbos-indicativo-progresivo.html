Presente Progresivo

Estar + gerundio: una acción ocurriendo justo en este momento.

Tiempos verbales/Indicativo/Presente Progresivo

🎬 Presente Progresivo

Formación: estar (presente) + gerundio

ESTAR + HABLANDO
yoestoy hablando
túestás hablando
él/ella/ustedestá hablando
nosotrosestamos hablando
vosotrosestáis hablando
ellos/ustedesestán hablando

Gerundio regular

-AR → -ando: hablando, trabajando
-ER → -iendo: comiendo, bebiendo
-IR → -iendo: viviendo, escribiendo

Gerundios irregulares frecuentes

pedir

→ pidiendo

dormir

→ durmiendo

decir

→ diciendo

venir

→ viniendo

poder

→ pudiendo

leer

→ leyendo

ir

→ yendo

morir

→ muriendo

Se usa para:

  • Una acción que ocurre justo ahora, en el momento de hablar: Estoy escribiendo un correo.
  • Nunca para hábitos ni verdades generales (para eso se usa el presente simple).
💡 A diferencia del inglés, el progresivo en español no se usa para planes futuros: "Mañana voy a Madrid", nunca "Mañana estoy yendo a Madrid".
